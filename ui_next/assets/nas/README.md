# NAS 전달자료 시연 자산

이 디렉터리는 전달받은 NAS 원본을 Streamlit이 매번 수 GB씩 읽지 않도록 만든 **소형 파생 자산**입니다. 원본 접속 정보와 계정은 저장하지 않습니다.

## 부산 4시점 시연 세트

`busan_2020/`은 `0_Busan` 입력–라벨 4쌍에서 만들었습니다.

- 관측일: 2020-02-18, 2020-03-12, 2020-03-25, 2020-04-14
- 관측 간격: 23일, 13일, 20일
- 원본 라벨: `0=비수체`, `1=수체`
- 원본 공간정보: EPSG:32652, 3 m × 3 m
- 공통영역: `(480933, 3888207, 509310, 3914898)`
- UI/API용 자산: 공통영역을 최근접 방식으로 512×512에 리샘플한 이진 PNG
- API 면적 환산: 원본 9 m²가 아니라 manifest의 리샘플 격자 면적 `2889.291790008545 m²/px`

광학영상은 문맥 표시용이고 API에는 `masks/`의 단일 밴드 이진 마스크만 전송합니다. 광학 센서는 날짜와 원본 폴더를 대조해 PlanetScope 계열로 추정했으며, 확정 센서 식별로 표현하지 않습니다.

이 세트는 실제 제공 영상·라벨에서 왔지만 수위 실측, 일별 미래 수체 정답, 검증된 학습 가중치는 없습니다. 따라서 수체 면적·마스크 연동 시연에는 사용할 수 있지만 수위 RMSE나 7·14·30일 모델 정확도를 주장할 수 없습니다.

재생성 스크립트는 [`scripts/extract_nas_busan_demo.py`](../../../scripts/extract_nas_busan_demo.py)입니다. 스크립트는 원본을 읽기 전용으로 열고 tar 스트림만 표준출력으로 내보냅니다.

## 분류 대표 썸네일

`representatives/`는 카탈로그에서 데이터 종류를 설명하기 위한 화면 전용 썸네일입니다.

- ICEYE quicklook: SAR 영상 미리보기
- PlanetScope UDM2: 구름·그림자·품질 마스크이며 수체 라벨이 아님
- 시립대 Pred_WB: 단일시점 파생 수체 결과
- 기흥·회동 browse: PAN/MUL 원천영상의 화면 미리보기

이 썸네일은 어떤 경우에도 시계열 예측 입력이나 성능평가 정답으로 사용하지 않습니다. 재생성 스크립트는 [`scripts/build_nas_representative_previews.py`](../../../scripts/build_nas_representative_previews.py)입니다.
