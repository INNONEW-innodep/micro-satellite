2촬영일 기준 실측 수위 원점 · D+1 · D+7 — 위성 연계 비교 지점

예측값과 비교되는 실제 관측값. 위 1번 자료에서 촬영일과 그 1일·7일 뒤 날짜의 값을 그대로 뽑은 것이다.

3수체 면적 Raw 데이터 위성 장면별 수체 탐지 면적

장면마다 탐지한 물 영역을 센서별 공통 격자(같은 창)에서 센 면적. 시계열로 비교하는 값은 공통 격자 면적 하나다. 예측은 앞 장면들의 공통 격자 면적으로 다음 장면의 공통 격자 면적을 맞히고, 그 다음 장면의 값이 비교 정답이다.

원본 JSON
    표의 값은 서버 API 응답을 가공 없이 그대로 보인 것이다(요약 타일도 자료 자릿수 그대로). 각 절의 원본 JSON 으로 서버 응답 원문을 직접 볼 수 있다.
