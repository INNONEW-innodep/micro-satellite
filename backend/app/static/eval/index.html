    이 화면은 무엇을 하나요

    새 지역이 와도 자료 수집부터 모델 성능 확인까지 한 줄로 끝내는 화면이에요. 왼쪽 "준비 상태"가 지역에 무엇이 갖춰졌는지와 다음 할 일을 알려 줘요.

    여섯 단계

    1. 지역 — 기존 지역을 고르거나 ID·이름으로 새로 만들어요.
    2. 수위 자료 수집 — WAMIS 관측소를 검색해 고르고 기간을 정하면 서버가 일 수위를 가져와요. CSV 업로드도 돼요.
    3. 기상 자료 수집 — 기상청 ASOS 지점의 일 강수·기온. 기상청 키가 없으면 표본 자료로 대신해요.
    4. 학습 — 학습·검증·시험 연도를 나누고 후보 모델을 골라요. 검증 연도에서 모델을 고르고, 시험 연도에서만 성적을 재요.
    5. 성능 평가 — 지점 × 예측일수 표, 모든 모델 계열의 전망 비교, 시험 연도 백테스트, 위성 면적 실험.
    6. 시험 — 원점 날짜를 골라 그날까지의 자료로 만든 전망을 실측과 비교해요.

    용어

    MSE
    오차 제곱의 평균 (m²). 작을수록 좋아요.
    RMSE
    MSE 의 제곱근. 수위와 같은 단위라 cm 로 보여 줘요.
    개선율
    직전값 유지(persistence) 대비 RMSE 가 얼마나 줄었나. +50 % 면 오차가 절반. 음수면 직전값 유지만 못해요.
    직전값 유지
    "내일도 오늘과 같다"는 가장 단순한 기준선. 모든 모델은 이것을 이겨야 의미가 있어요.
    원점
    전망을 만드는 기준 날짜. 그날까지의 자료만 써요.
    5–95 % 범위
    검증 연도 잔차에서 계산한 경험적 산포. 모델 신뢰구간은 아니에요.
