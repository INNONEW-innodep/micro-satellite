TTA-26-03423  TC2  시험 수행 절차  (수체면적 및 수위변화 시계열 예측 정확도, 종합 MSE 0.38 이하)
================================================================================
시험대상      : WATERCAST v0.2.0  (분석 PC 에서 컨테이너로 구동)
분석 PC       : 172.18.10.113  (Ubuntu, 계정 innonew98, 저장소 /home/innonew98/micro-satellite)
클라이언트 PC : Windows, 브라우저 + 터미널(PowerShell 또는 명령 프롬프트, ssh·scp 내장)
소요 시간     : 스크립트 1회 약 2분 30초
--------------------------------------------------------------------------------

[0] 준비  — 이노뎁 담당자가 시험 전에 해 둔다
 0-1. 분석 PC 에서 시험대상을 올린다. (--build 를 꼭 붙인다)
        cd /home/innonew98/micro-satellite
        docker compose up -d --build watercast
        curl -s localhost:18000/api/v1/health
      → {"status":"ok", ...} 가 나오면 준비 끝.
 0-2. 클라이언트 PC 브라우저에서 http://172.18.10.113:18000/data 가 열리는지 본다.
      안 열리면 분석 PC 에서 아래를 실행하고 다시 연다.
        sudo ufw allow from 172.18.10.0/24 to any port 18000 proto tcp
 0-3. 클라이언트 PC 터미널이 UTF-8 인지 본다. (Windows Terminal·PowerShell 은 기본. PuTTY 는 Translation = UTF-8)

[1] 시험 방법 (1)  대상 지역과 보유 자료 확인  — 클라이언트 PC 브라우저
 1-1. http://172.18.10.113:18000/data 를 연다.
 1-2. 첫 줄 타일에서 다음이 보이는지 확인한다.
        지역            : 낙동강 하구 (부산·김해)
        수위 자료 기간  : 2015.1.1 ~ 2024.12.31, WAMIS 일 수위
        수위관측소      : 6곳 (위성 연계 비교 지점 3곳 = 구포대교·호포대교·정천교)
        초소형위성 장면 : 8장면 (ICEYE 4 · PlanetScope 4), 그 아래 촬영일 칩 8개 (2020.2.18 ~ 2020.4.16)
        시험 연도       : 2020 (= 위성 촬영 연도), 이번 시험에 쓰는 구간 2015.1.1 ~ 2020.12.31
 1-3. 자료 상세가 필요하면 같은 화면을 아래로 내린다.
        ① 수위 Raw 데이터        : 관측소 6곳 일 수위 (표·그래프·CSV·원본 JSON)
        ② 촬영일 기준 실측 수위  : 비교 지점 3곳 × 촬영일 8 = 24건 (원점·D+1·D+7 실측)
        ③ 수체 면적 Raw 데이터   : 장면 8장의 공통 격자 수체 면적.
                                    머리의 "어디 / 영상 / 수체 판정" 세 줄 = 지역·창 위치, 영상 센서·기간·원본 파일명, 수체 판정 방식
      (서비스 화면 http://172.18.10.113:18000/app 도 같은 지역의 장면 8개와 관측소 6곳을 보인다.)

[2] 시험 방법 (2)  시험용 스크립트 실행  — 클라이언트 PC 터미널
 2-1. 분석 PC 에 SSH 로 접속한다. (접속 비밀번호는 이노뎁 담당자)
        ssh innonew98@172.18.10.113
 2-2. 저장소 폴더에서 스크립트를 실행한다. (아래 한 줄을 그대로 붙여 넣는다)
        cd /home/innonew98/micro-satellite && mkdir -p ~/tta && python3 scripts/eval_iitp_indicator.py --json-out ~/tta/tc2_result.json --text-out ~/tta/tc2_result.txt
 2-3. 화면에 아래 순서로 진행이 찍힌다. 전체 약 2분 30초.
        [1/4] 수위 예측 모델 학습  — 관측소 6곳을 하나씩 학습한다. 지점마다 "학습 중 …" 과 "완료" 가 찍힌다.
        [2/4] 수위 예측            — 위성 촬영일 원점 24건, D+1 · D+7
        [3/4] 수체면적 예측        — 관측 8시점, 인접쌍 6개 (학습 없음)
        [4/4] 지표 산출
      중간에 끊기면 2-2 의 한 줄을 다시 실행한다. (처음부터 다시 돌고 결과는 같다)

[3] 시험 방법 (3)  예측값·실측값 비교표 확인  — 2-3 이 끝난 화면
 3-1. "■ 수위 예측 — 예측값·실측값 비교표 (단위 m)"
        24행 (구포대교·호포대교·정천교 × 촬영일 8). 행마다 D+1 대상일·예측·실측·오차, D+7 대상일·예측·실측·오차.
        아래 줄 "지점별 시험연도 수위 관측범위(정규화 분모)" 에 3개 값.
 3-2. "■ 수체면적 예측 — 예측값·탐지값 비교표 (단위 km², 공통 격자 ...)"
        6행 (ICEYE 3, PlanetScope 3). 아래 줄 "수체면적 관측범위(정규화 분모)".
 3-3. 실측값·탐지값은 [1] 의 /data 화면 ②(수위)·③(면적) 에 있는 값과 같다.

[4] 시험 방법 (4)  판정
 4-1. "■ 지표" 표에서 D+1 행과 D+7 행의 "종합 MSE" 가 각각 0.38 이하이고 "판정" 이 "적합" 인지 확인한다.

[5] 결과 파일 보관  — 클라이언트 PC
 5-1. 화면 마지막에 다음 두 줄과 scp 한 줄이 찍힌다.
        결과 JSON 저장 : /home/innonew98/tta/tc2_result.json
        화면 출력 저장 : /home/innonew98/tta/tc2_result.txt
        scp innonew98@172.18.10.113:/home/innonew98/tta/tc2_result.json innonew98@172.18.10.113:/home/innonew98/tta/tc2_result.txt .
 5-2. 클라이언트 PC 에서 터미널 창을 하나 더 열고, 결과를 둘 폴더로 이동(cd)한 뒤 그 scp 한 줄을 붙여 넣는다.
      비밀번호를 넣으면 tc2_result.txt (화면의 표·판정 그대로) 와 tc2_result.json (계산 상세) 이 그 폴더에 내려온다.

[6] 시험 종료 후  — 이노뎁 담당자
 6-1. SSH 터미널에서 학습 산출물을 되돌린다.
        python3 scripts/eval_iitp_indicator.py --restore
 6-2. 분석 PC 에서 아래가 "origin":"builtin" 이면 끝.
        curl -s localhost:18000/api/v1/regions/nakdong_busan | grep -o '"origin":"[a-z]*"'

[참고]
 - 스크립트는 시험대상의 공개 API 만 호출한다. 비교에 쓰는 실측·탐지값은 /data 화면에 보이는 원자료 그대로다.
 - 시험 전날 리허설은 --station-pause 0 을 붙여 간격 없이 약 30초로 돌리고, 끝나면 반드시 --restore 로 되돌린다.
