```
<시험목표>

초소형위성(ICEYE SAR, PlanetScope 광학) 관측 시점을 예측 원점으로 하여 산출한
수위 및 수체면적의 시계열 예측 정확도(정규화 MSE)가 0.38 이하인지 확인

 ※ 예측 대상 ① : 하천 수위 (단위 m)
    - 대상 지점 : 초소형위성 수체 산출 위치와 연계된 수위관측소 3개소

    - 예측 원점 : 초소형위성 촬영일 8일 × 수위관측소 3개소 = 24건
    - 평가 예측일수 : D+1(익일), D+7(7일 후)

 ※ 예측 대상 ② : 위성영상 탐지 수체면적 (단위 km²)
    - 대상 구역 : 낙동강 하구 테스트베드
    - 평가 시점 : 차기 위성 관측시점 (실제 관측 간격 1~28일)
    - 위성은 매일 촬영되지 않으므로 수체면적은 D+1/D+7 로 표기하지 아니한다.

<측정지표>

o 산정식

  ① 변수별 정규화
     x̃ = ( x - x_min ) / ( x_max - x_min )
     ※ x_min, x_max 는 시험 구간에서 실측된 최솟값·최댓값

  ② 수위 정규화 MSE
     MSE_L(h) = (1/K) × Σ ( ŷ_k - y_k )² / R_s(k)²
     - K   : 예측 원점 수 (24)
     - h   : 예측일수 (1 또는 7)
     - ŷ_k : 원점 k 에서 산출한 h 일 후 예측 수위 (m)
     - y_k : 해당 일자의 수위관측소 실측 수위 (m)
     - R_s : 지점 s 의 시험연도(2020) 수위 관측범위 (m)

  ③ 수체면적 정규화 MSE
     MSE_A = (1/M) × Σ ( Â_m - A_m )² / R_A²
     - M   : 인접 관측쌍 수 (6 = 센서별 3쌍 × 2센서)
     - Â_m : 평균회귀 모델이 차기 관측시점에 대해 산출한 예측 수체면적 (km²)
             Â = A_prev + 0.5 × ( mean(A_1..A_prev) − A_prev )
             ※ 그 시점까지 관측된 값만 사용한다(미래 관측 미사용).
     - A_m : 차기 관측시점의 탐지 수체면적 (km²)
     - R_A : 시험 구간 수체면적 관측범위 = 11.34 km²
             (두 센서 공통 격자 계열 8시점을 합친 최댓값 40.21 − 최솟값 28.87)

     ※ 수체면적은 센서별 '공통 격자'(전 날짜가 공통으로 촬영한 동일 범위·동일 화소)
        에서 산출한다. 초소형위성은 날짜마다 촬영 범위가 조금씩 달라, 장면별 자기
        촬영범위에서 센 면적을 나열하면 촬영 범위의 변화가 수체 변화로 나타난다.
        공통 격자는 측정 구역을 고정하기 위한 것이며, 수체탐지 정확도(IoU)와는
        별개의 축으로 탐지 성능과는 무관하다.

  ④ 종합 지표 (판정 대상)
     MSE(h) = ( MSE_L(h) + MSE_A ) / 2

  ※ 수위(m²)와 수체면적((km²)²)은 단위가 상이하여 직접 합산할 수 없으므로,
     각 대상의 실측 관측범위로 [0,1] 정규화한 후 동일 가중으로 평균한다.

o 산정 방법

  (1) 지상 수위관측소의 일 수위 시계열을 학습 구간(2018-12-31 이전) /
      검증 구간(2019년) / 시험 구간(2020년)으로 분리한다.
  (2) 검증 구간에서 기준선(직전 관측값 유지) 대비 MSE 가 가장 낮은 예측모델을
      지점별·예측일수별로 선택한다. 기준선은 비교 대상일 뿐 선택 후보가 아니다.
  (3) 학습·검증에 사용하지 않은 2020년에서, 초소형위성이 촬영한 날짜를 예측 원점으로
      하여 D+1·D+7 수위를 예측하고 동일 일자의 수위관측소 실측값과 비교한다.
  (4) 수체면적은 초소형위성 영상에 수체탐지 모델(WBMS)을 적용하여 산출한 수체
      마스크를 센서별 공통 격자에 정합한 뒤 면적을 산출하고, 그 시점까지의 관측만
      사용하는 평균회귀 모델로 차기 관측시점의 면적을 예측하여 실측 면적과 비교한다.
      비교 대상으로 기준선(직전 관측값 유지) 성적을 함께 산출한다.
  (5) (3)과 (4)의 오차를 각 대상의 관측범위로 정규화한 후 동일 가중으로 평균하여
      종합 MSE 를 산출하고, 0.38 이하 여부를 판정한다.
  (6) 예측 원점의 유효성은 위성 산출 수위와 동일 일자 수위관측소 실측값의 대조로
      별도 확인한다(위성 산출 수위 30건 중 수위관측소와 짝지어지는 22건,
      RMSE 3.2 cm).
```

## 6) 시험 중 질의 예상 — 답변 문안

**Q. 위성으로 예측한다면서 예측모델은 지상 수위계로 학습한 것이 아닌가?**

```
학습은 지상 수위관측소 자료로, 관측은 초소형위성으로 수행하는 역할 분담 설계이다.
초소형위성 관측은 8시점에 불과하여 시계열 모델의 학습 자료로는 사용할 수 없으며,
수위관측소의 10개년(2015~2024) 일 단위 자료를 시간 순서로 나누어 — 본 시험에서는
2015~2018년으로 학습하고 2019년으로 모델을 고른다 — 하천 수위의 거동을 학습하고
위성으로 현재 상태를 관측하는 구조이다. 이는 수위관측소가 설치되지 않은 지역으로
확장할 때의 운용 형태와 동일하다.

두 관측값의 차이는 가정이 아니라 실측으로 확인하였다.
 - 위성 산출 수위 vs 동일 일자 수위관측소 실측 : RMSE 3.2 cm (대조 22건, 최대 6.9 cm)
 - 이는 D+1 예측 오차(RMSE 4.8 cm)보다 작다.

또한 예측 원점의 관측값을 수위관측소 실측값에서 위성 산출 수위로 치환하여 예측
전 과정을 재실행한 결과는 다음과 같다.
 - D+1 : 예측값 변화 평균 1.4 cm (최대 3.8 cm) — 종합 MSE 판정 불변
 - D+7 : 예측값 변화 평균 0.2 cm (최대 0.8 cm) — 종합 MSE 판정 불변
   ※ 위 변화량은 수위 항에만 영향을 주며, 종합 MSE 는 소수 셋째 자리에서 변하지 않는다.
즉 어느 값을 예측 원점으로 사용하여도 판정 결과는 변하지 아니한다. D+7 에서 차이가
더 작아지는 것은 선택된 모델이 평균회귀 특성을 가져 예측일수가 길수록 원점 값의
영향이 감소하기 때문이다.

다만 위 확인은 2020년 갈수기 조건에서 수행된 것으로, 홍수기와 같이 수위가 급변하여
위성 산출 수위의 오차가 커지는 조건에서는 재확인이 필요하다.
```

**Q. 예측모델이 기준선(직전값 유지)보다 나은가?**

```

 - 위성 원점 24건 : 모델 MSE 0.00118 vs 기준선 0.00177 — 기준선 대비 33.6 % 개선
   (RMSE 3.4 cm vs 4.2 cm)
 - 수체면적 인접쌍 6개 : 평균회귀 정규화 MSE 0.02663 vs 기준선 0.02934 — 9.2 % 개선
 - 전국 7개 유역 26개 지점 2024년 홀드아웃 : 보고 지평 182셀 중 178셀에서 기준선보다 우수
예측일수 D+1 의 위성 원점 24건에서는 모델 MSE 0.00233 으로 기준선(0.00128)보다 낮은
성능을 보였다. 이는 정천교 2건(2020-03-25 오차 16.5 cm, 2020-04-16 12.7 cm)이 전체를
지배한 결과로, 표본 24건 중 2건이 제곱오차의 대부분을 차지한 데 기인한다. 정천교는
유역이 작아 강우 응답이 빠른 지류 지점이다.
본 시험의 측정지표는 정규화 MSE 이며 기준선 대비 개선율은 판정 대상이 아니다.
D+1·D+7 모두 종합 정규화 MSE 는 목표 0.38 을 만족한다(0.014 / 0.013).
```

**Q. 왜 정규화하여 합산하는가?**

```
수위의 MSE 는 m², 수체면적의 MSE 는 (km²)² 로 단위가 상이하여 직접 합산할 수 없다.
따라서 각 대상의 실측 관측범위로 [0,1] 정규화한 후 동일 가중으로 평균한다.
참고로 정규화 전 원단위 수위 MSE 는 전국 26개 지점 평균 기준 D+1 0.033, D+7 0.215,
D+30 0.685 로, 예측일수가 길어지거나 댐 지점을 포함할 경우 목표값 0.38 을 초과한다.
본 시험에서 판정 범위를 D+7 까지로 한정한 것도 같은 이유이다.
```
