# 낙동강 하구 위성 대조 지점(구포·호포·정천 + 양산) 시계열 그래프 자료 — 삼랑진교 대체용 (2026-10-16 03시)

읽는 사람: 발표자료 3.2~3.4·3.7 의 삼랑진교 그래프를 위성 수위 대조 지점으로 바꾸는 agent.

모든 수치는 배포 API(https://wc-api.semyeongsoft.com)와 저장소 산출물(`regions/nakdong_busan/models/gauge/*`)에서 `scripts/build_satellite_station_deck_data.py` 가 읽어 `docs/presentation/data/timeseries_deck_data.json` 에 넣은 것이다. 합성값 없음. 양산교는 시립대 모델 2(신뢰 게이트) 지점이라 함께 넣었다. 삼랑진교 항목은 지우지 않았다(언급용).

## 6. 덱에 쓸 문장(제안)

- 3.2: 위성이 관측한 바로 그 지점(구포·호포·정천)에서 지상 수위 기준 예측이 성립 — D+7 7.8 · 15.4 · 17.9 cm(+51 · +46 · +49 %), 공식 지표 24건 원점도 같은 계열.
- 3.3 전망 예시: 구포대교 2024-07-01 원점 30일 RMSE 19.8 cm(직전값 20.7, +8.6 %) · 호포대교 40.3 cm(41.7, +6.4 %) — 상승 방향은 맞으나 폭을 따라가지 못함. 완전 예보를 넣어도 19.0 / 38.1 cm 라 예보만으로는 안 풀린다(하굿둑 조절·방류 입력 필요).
- 3.4 백테스트: 구포 D+7 7.8 cm(직전값 11.1) · 호포 15.4 cm(직전값 21.0).
- 3.7 월별: 급변 57일이 구포 80 % · 호포 89 % · 정천 73 % 의 제곱오차를 차지, 제외하면 3.8 · 5.6 · 10.2 cm.
- 정천교·양산교는 2024-07-01 사례에서 직전값 유지보다 나쁘다(11.9 vs 9.7 · 13.5 vs 6.2 cm) — 전망 예시 그래프는 구포·호포로 하고 정천·양산은 표에만.
- 삼랑진교는 '본류 급변 사례(위성 범위 밖)'로 한 줄만 언급.
