# 수체 면적 시계열 — 두 방식을 같은 자료로 실증 (2026-10-15)

발표 슬라이드 재료. 수치는 전부 `scripts/eval_level_area_bridge.py` 가 저장소 자료로 계산한 값(`docs/presentation/data/level_area_bridge.json`,
표 전체는 `수위면적다리_실증_2026-10-15.md`). 합성값 없음.

## 1. 한 줄

면적 시계열은 두 길로 만든다. **① 면적 자체 모델**(직전값 유지 · 평균회귀 · 면적 추세 — 공식 지표는 평균회귀)과
**② 수위 전망에 종속시킨 면적**(수위-면적 다리: 면적(t+h) = 마지막 탐지 면적 + 기울기 × (수위 전망(t+h) − 원점 수위)).
둘 다 서비스 화면 ④ 에서 모델로 고를 수 있고(`level-area-bridge` 추가), 같은 장면쌍·같은 지표로 비교했다.

## 2. 방식 ② 가 무엇인가

| 항목 | 내용 |
|---|---|
| 식 | 면적(t+h) = A_last + b × (ĥ(t+h) − h₀). A_last 마지막 탐지 면적(공통 격자), h₀ 원점 실측 수위, ĥ 지점 수위 예측기(검증 선택 모델) 전망 |
| 기울기 b | 대청댐 **0.47 km²/m** — 국토지리정보원 3 m DEM 의 73.5~76.5 m 구간 수위-면적 곡선(본댐 호수, 공통 격자 안). 부산 **0** — 제방 하도(제방 안에서 면적은 수위에 둔감). 지역 매니페스트 `satellite.level_area` |
| 대안 기울기 | 위성 장면 같은 날 (수위, 면적) 적합 — 대청 2022년 5장 +2.74 km²/m(r=+0.86, 수위폭 0.54 m). 평가에는 '같은 배치 LOO 적합'으로 넣었다 |
| 구현 | `backend/app/adapters/level_area_bridge.py` (예측 API `model_id=level-area-bridge`, 옵션 region_id·station_id·slope_km2_per_m·anchor), 서비스 ④ "수위-면적 곡선 연동" |
| 변형 | anchor=mean_reversion: 출발 면적을 평균회귀값으로 — 공식 면적 모델에 수위 항을 더한 형태 |

## 3. 결과 — 인접 장면쌍 전망 (원점 장면 → 다음 장면, 같은 센서·같은 배치, Δ ≤ 30일)

읽는 법
- 기울기를 **물리 근거(DEM)로 두면** 다리는 기존 면적 모델과 같거나 조금 낫다(대청 유효범위 +25~30 %). 인접 장면 사이 수위 변화가 0.5 m 이하라 수위 항(≤ 0.25 km²)이 마스크 잡음(1일 재방문 차 2.4 km²)보다 작기 때문에 차이가 작다.
- 기울기를 **위성 장면에서 적합하면** 부산에서는 치명적이다(수위 변동 3.6 cm 에 면적 잡음을 맞춘 170 km²/m). 대청 2019 배치도 덮개율 때문에 거꾸로 간다. → 기울기는 DEM·공식 곡선에서, 위성은 확인용.
- 두 방식의 차이가 드러나려면 수위가 크게 움직이는 구간(홍수기)의 장면이 필요하다 — 현재 표본(갈수기·안정기)에서는 "같다"가 결론이다.

2022년(마스크 상호 IoU 0.93)에서만 수위와 면적이 같이 움직인다. 2019년(상호 IoU 0.61, 덮개율 59~87 %)은 같은 수면을 장면마다 다르게 잡은 것이라 관계가 뒤집힌다. 부산은 수위가 안 움직여 관계를 잴 수 없다.

## 5. 수위 시계열 → 면적 시계열 (대청댐 2024, 그림 `figures/level_area_bridge_daecheong_2024_derived.png`)

면적(t) = 18.02 + 0.47 × (수위(t) − 70.89). 2024년 실측 수위(69.9~78.9 m)로 환산한 면적 17.6~21.8 km², D+7 수위 전망(GRU, RMSE 1.19 m)으로 환산한 면적의 RMSE **0.56 km²**(= 0.47 × 1.19). 위성 검증은 없다(2024 장면 없음) — "면적 시계열이 수위 시계열에서 나온다"는 구조를 보이는 그림이며, 기울기가 바뀌면(공식 곡선) 세로축만 바뀐다.

## 7. 말할 수 있는 것 / 없는 것

- 할 수 있다: 두 방식 모두 구현돼 같은 화면에서 돌고, 같은 쌍·같은 지표로 비교된다. 수위 종속 방식은 수위 예측 성적(부산 41/42·대청 21/21 셀)을 그대로 면적으로 옮기며, 오차는 기울기 × 수위 오차로 정량화된다.
- 아직 못 한다: 현재 위성 표본(갈수기·안정기 18장면)으로는 두 방식의 우열이 마스크 잡음 안에 있다. 기울기의 공식 근거(K-water 수위-저수면적 곡선)와 홍수기 장면이 들어오면 그때 갈린다.
- 하지 말 것: 위성 장면 몇 장으로 기울기를 적합해 쓰는 것(부산 −120 %).
