# 2세부 발표자료 정합 수정 정리 (2026-10-16 새벽) — 다른 agent 인계용

읽는 사람: 이 저장소를 이어받아 10/16 IITP 전체회의 2세부 발표자료를 마무리하거나 검토할 agent/동료.
이 문서는 "무엇을, 왜, 어디에" 고쳤는지와 아직 열려 있는 확인 사항을 한곳에 모은 것이다. 상세 근거는 각 절의 파일 경로를 따라가면 된다.

## 0. 결론 먼저

- **발표 순서는 서울시립대 → 이노뎁.** 시립대는 자기 자료(`발표자료_서울시립대학교_V1.pptx`, 45장)로 먼저 발표하고, 이노뎁은 2세부 덱 v6 로 이어서 발표한다. 두 파일은 **슬라이드 비율이 달라**(시립대 A4 780×540 pt, 우리 16:9 960×540 pt) 한 pptx 로 합치지 않았다. 합치면 한쪽이 찌그러진다. PowerPoint 의 "슬라이드 다시 사용"도 같은 문제가 난다.
- **산출물 3개** (`docs/presentation/incoming/`):
  1. `초소형위성_2세부_진행현황_실증결과_v6_시립대V1정합.pptx` — 사용자 덱 v5(42장)를 시립대 V1 수치·순서에 맞춰 고친 것. 원본은 `…_v5.pptx` 와 `…_v5_원본백업.pptx` 그대로.

## 4. 동료 메모(10/15) 답변 요약 — 상세는 답변 md

- **A~F 불일치**: A 탐지 대표값은 시험 장면 1건(합산 0.927/0.941 은 학습 장면 포함이라 대표 금지) · B 부산 위성 수위 1~4.5 cm 는 8월 인수 LSTM v3 번들(= 시립대 모델 1, 같은 4지점 30건)의 **표본 내** 값, 공식 LODO 4.53 cm · C K-water 교차 IoU 0.68~0.71 은 자체 전처리 참고값, 공식은 시립대 Umbra 0.755~0.772 · D 패키지 wbms:0.13(8/20) 탑재, v1 미수령 · E 시립대 지표는 F1·융합 수위 2개 + 선박 탐지 F1(별도 파트) · F 용어 통일(수위 산정·융합 보정).
- **추가 데이터 5건**: 9지점 2024 변동폭(최대−최소) 낙동강하구언 0.44 · 구포 1.04 · 호포 1.89 · 양산 1.76 · 삼랑진 4.10 · 정천 2.91 · 대청댐 8.96 · 조정지 2.86 · 방수로 3.29 m; 부산 3지점 위성 수위 기록별 값(`docs/presentation/data/timeseries_deck_data.json busan_levels`); 부산 공통 격자 면적 ICEYE 40.21·36.61·36.74·39.13 / PS 30.15·28.87·30.15·30.97 km² 와 인접쌍 6개(덱 노트 23); "2022년 5월 5장 7~9 cm" 는 틀림 → **8~17 cm(RMSE 13.5 cm)**; wbms:v1 미수령.
