# 🛰️ 발표용 파이프라인 데모 UI

초소형 위성 SAR 영상 기반 **수체 시계열 분석 파이프라인** 데모 화면입니다.
발표 시연을 위해 단계별(STEP 1 → STEP 2 → STEP 3 → STEP 4)로 진행됩니다.

## 흐름

```
[입력 SAR 영상]
     │
     ▼  (1차 처리 버튼)
[U-Net 수체 탐지]  ──→  수체 마스크 + 면적/비율
     │
     ▼  (자동 연동)
[기상청 데이터]    ──→  강수량/기온/습도 차트
     │
     ▼  (2차 처리 버튼)
[ConvLSTM 시계열 예측]  ──→  미래 시점 수체 분포 + 변화율 + 위험 평가
```

## 실행

```bash
cd pipeline_ui
bash run.sh
```

처음 실행 시 의존성을 자동으로 설치합니다. 브라우저에서 `http://localhost:8501` 로 접속하세요.

원격 서버에서 실행하는 경우 SSH 포트포워딩:

```bash
ssh -L 8501:localhost:8501 <서버>
```

## 사이드바 설정

| 항목 | 설명 |
|------|------|
| 관측 지역 | 부산/서울/대구/광주 |
| 관측 일자 | 시계열 분석의 기준 시점 |
| 입력/예측 시퀀스 길이 | ConvLSTM 의 N → M 길이 |
| 기상청 API 키 | 비워두면 샘플 데이터 사용 |
| 탐지 모델 / 시계열 모델 | 모델 선택 (표시용) |
| 이진화 임계값 | SAR 임계값 (수체 탐지에 영향) |

## 발표 시연 팁

1. **"부산 - 낙동강 하구"** 샘플로 시작 — 가장 자연스러운 시각화
2. **"광주 - 홍수 시나리오"** 로 변경 → 변화율이 크게 증가 → "홍수 위험" 태그
3. **"한강 - 가뭄 시나리오"** 로 변경 → 변화율이 감소 → "가뭄 위험" 태그
4. 사이드바의 임계값을 슬라이드하며 수체 탐지가 어떻게 달라지는지 시연
5. 마지막 STEP 4 의 `3세부 시뮬레이션 연계` 태그로 마무리

## 참고

- 본 화면은 **시연용 데모**입니다. 실제 추론은 학습된 모델 가중치(`busan_model.weights.h5`)를 사용하며,
  현재는 발표 용도로 합성 데이터 + 형태학적 처리로 결과를 모사합니다.
- 실 모델로 교체하려면 `app.py` 의 `detect_water()` 와 `predict_future()` 를 wrapper 로 치환하면 됩니다.
